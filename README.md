# 🎰 Slot Machine｜簡易拉霸機

可規劃邏輯設計－利用 FPGA 實作簡易拉霸機。

## 一、專案介紹

利用 FPGA、Verilog 與機器碼設計，實作具有三個七段顯示器的簡易拉霸機。

共設計兩個版本，分別呈現不同的數字循環速度、停止機制及 LED 顯示效果。

---

## 二、版本一：獨立加速拉霸機

### 功能介紹

- reset 為高電位時，初始畫面顯示「go」。
- 撥動 SW[3] 至 1，啟動 seg[0] 的數字循環。
- 撥動 SW[0] 至 1，seg[0] 立即停止，並啟動 seg[1] 的數字循環。
- seg[1] 的循環速度比 seg[0] 更快。
- 撥動 SW[1] 至 1，seg[1] 立即停止，並啟動 seg[2] 的數字循環。
- seg[2] 的循環速度比 seg[1] 更快。
- 撥動 SW[2] 至 1，seg[2] 立即停止。
- 當三個七段顯示器的數字完全相同時，8 顆 LED 全部閃爍。

### 版本特色

三個七段顯示器依序啟動，且每個顯示器具有不同的循環速度，藉此呈現逐步加速的拉霸效果。數字停止時採取立即停止的方式。

---

## 三、版本二：漸慢停止與中獎動畫拉霸機

### 功能介紹

- 初始畫面顯示「go」。
- reset 為高電位時開始作動。
- 三個七段顯示器進行數字循環。
- 利用 SW 控制各個數字停止。
- 停止時逐漸降低數字循環速度，最後才完全停止。
- 自動判斷三個數字是否相同，並依照結果控制 LED。

### LED 顯示規則

| 判斷結果 | LED 顯示效果 |
|---|---|
| 三個數字皆不同 | 8 顆 LED 全暗 |
| 兩個數字相同 | 中間 4 顆 LED 亮起 |
| 三個數字全部相同 | 播放中獎 LED 動畫，最後 8 顆 LED 全亮並保持 |

### 版本特色

相較於版本一的立即停止，版本二加入漸慢停止機制，讓七段顯示器的數字在停止前逐步降低循環速度，呈現更接近實際拉霸機的減速效果。

## 六、版本比較

| 比較項目 | 版本一 | 版本二 |
|---|---|---|
| 數字啟動方式 | 依序啟動 | 依 SW 控制 |
| 數字循環速度 | 逐步加快 | 依原程式設定 |
| 停止方式 | 立即停止 | 逐漸減速後停止 |
| 中獎判斷 | 三個數字相同 | 三個數字相同 |
| LED 效果 | 8 顆 LED 閃爍 | 依結果顯示不同效果 |
