# slot_machine
可規劃邏輯設計_簡易拉霸機

## 一、專案介紹
利用 FPGA 與 Verilog / 機器碼設計，
實作具有三個七段顯示器的拉霸機。

## 二、功能介紹
- 初始畫面顯示go
- reset為高電位時開始作動
- 三個七段顯示器數字循環
- 利用 SW 控制數字停止
- 判斷三個數字是否相同
- 透過 LED 顯示不同的結果
- 數字不同：LED全暗
- 兩個相同：亮中間4顆 LED
- 全部相同：播放中獎 LED 動畫並保持全亮
